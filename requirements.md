# Rental Assistant Agent

## Problem
I spend time repeatedly answering the same rental questions and coordinating showings with prospective tenants.

## Goal
Build an AI rental assistant that handles routine questions and showing requests while escalating anything requiring human judgment.

## Users
- Prospective tenants
- Property manager

## The Agent Can
- Answer approved property FAQs
- Tell prospects whether a property is available
- Provide rent and utility information
- Provide showing availability
- Collect prospect contact information
- Record a showing request
- Provide an application link
- Escalate questions to the property manager

## The Agent Cannot
- Approve or deny applicants
- Decide whether someone qualifies
- Rank applicants
- Make exceptions to rental policies
- Negotiate lease terms
- Answer questions involving protected characteristics
- Make consequential tenant-selection decisions
